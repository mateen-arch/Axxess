# Axxess Healthcare Platform - Modern Redesign

Enterprise Home Health, Home Care & Hospice Management System built with a unified, state-of-the-art tech stack.

## Architecture Overview

```
d:/Axxess/
├── frontend/             # Next-Gen React Web Application (Vite + TS + Modern Design System)
├── backend/              # Node.js + Express + TypeScript REST API
├── database/             # PostgreSQL Schema, Relational Models, Seeds, & Performance Indexes
├── mobile/               # React Native Clinician & Field Nurse Application (EVV & Field Charting)
├── shared/               # Shared TypeScript Contracts, Enums & Domain Interfaces
├── package.json          # Workspace Root Configuration
└── README.md
```

## System Modules
- **Modern Sidebar & Command Center (`Ctrl+K`)**: Rapid navigation across clinical modules.
- **Bento Grid Dashboard**: High-density visual metrics with Glassmorphism cards, donut chart census visualization, and interactive quick filters.
- **Patient Census & Active Directory**: Real-time distribution across Home Health, Home Care, and Hospice.
- **Central Intake & Referrals**: Visual Kanban / Stage tracker from initial inquiry to admission.
- **Schedule Center & Unassigned Visits**: Interactive dispatch, clinician matching, and visit verification.
- **HIPAA-Compliant Communication Hub**: Clinician messages, supervisor audit logs, and instant notifications.
- **Care Intelligence & Education Feed**: Integrated video player and news updates.
